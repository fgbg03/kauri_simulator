# kauri_simulator
Simulator for the Kauri BFT consensus protocol extended for dynamic adaptation.

# Files

**sim_main** - main file

**consensus** - impelements Kauri's behaviour

**epoch_evaluator** - various metrics to score an epoch schedule

**epoch_generator** - generates an epoch schedule from trees

**node** - Kauri node, includes reputation attribute

**reputation** - reputation adjustment logic

**tree_evaluator** - various metrics to score a tree

**tree_generator** - generates trees from a collection of nodes

**tree** - Kauri tree representation
